PONNU プロジェクト 他PCセットアップ手順書

対象: nfcchipplatform/ponnu リポジトリ  |  公開URL: https://ic.ponnu.net/

機密情報の取り扱いについて
本書には FTP / DB パスワード等の機密情報は 一切記載していません。 パスワード類はすべて パスワードマネージャ（1Password / Bitwarden 等）または暗号化チャット 経由で別途共有してください。 GitHub / メール / Slack 公開チャンネル等にパスワードを貼り付けることは絶対に禁止です。

全体の流れ

[メインPC] ──push──▶ [GitHub: Private] ──clone──▶ [他PC] + 機密ファイルは別経路で受け渡し

フェーズA: メインPCで1回だけやること（GitHub準備）

A-1. GitHubリポジトリを作成（手動・ブラウザ操作）

  1. ブラウザで https://github.com/new を開く
  2. 以下を入力:
    • Owner: nfcchipplatform
    • Repository name: ponnu
    • Private を選択（必須）
    • README / .gitignore / license は 全部チェックなし
  3. 「Create repository」をクリック

A-2. 機密の安全化と初回push（自動実行）

下記の機密情報を含むファイルは .gitignore で除外され、GitHubには上がりません:

  • app/config.php （DB接続情報・APP_SECRET）
  • deploy.ps1 （FTPパスワード）
  • SETUP_OTHER_PC.html （旧ローカルメモ）

代わりに以下のテンプレートのみが共有されます:

  • app/config.example.php （プレースホルダのみ）
  • deploy.ps1.example （<YOUR_FTP_PASSWORD> プレースホルダ）

フェーズB: 他PCで1回だけやること

B-1. Git for Windows をインストール

  1. https://git-scm.com/download/win から「64-bit Git for Windows Setup」をDL
  2. インストーラーを実行（すべてデフォルトで「Next」連打でOK）
  3. PowerShellを開いて確認: 
    git --version
    → git version 2.xx.x と出ればOK

B-2. GitHubアカウントでログイン

  1. ブラウザで https://github.com/login にアクセスして nfcchipplatform でログイン
  2. git clone 実行時、自動で「Sign in with your browser」のポップアップが出る → 承認

B-3. プロジェクトをダウンロード

# (1) 作業フォルダを作る
mkdir C:\projects
cd C:\projects

# (2) GitHubから取得
git clone https://github.com/nfcchipplatform/ponnu.git

# (3) プロジェクトフォルダに移動
cd ponnu

B-4. 機密ファイルの復元（GitHubには上がっていない）

下記ファイルは パスワードマネージャ等から個別に取得 してください。Git管理されていません。
ファイル取得・配置方法
app/config.php (1) テンプレートをコピー: 
copy app\config.example.php app\config.php
(2) notepad app\config.php で開き、以下の値をパスワードマネージャから貼り付け:
  • DB_HOST, DB_NAME, DB_USER, DB_PASS
  • APP_URL, APP_SECRET
  • UPLOAD_DIR （他PCの絶対パスに合わせる）
  • メール送信を使う場合は MAIL_*
deploy.ps1 (1) テンプレートをコピー: 
copy deploy.ps1.example deploy.ps1
(2) notepad deploy.ps1 で開き、<YOUR_FTP_PASSWORD> をパスワードマネージャから取得した実際のパスワードに置換
(3) $localBase を他PCの絶対パスに変更

B-5. 動作確認

git status

→ nothing to commit, working tree clean と出ればOK（gitignore対象は表示されない）

フェーズC: 以降の日々の作業（両PC共通）

作業を始める前（毎回）

cd C:\projects\ponnu
git pull

作業が終わったら（毎回）

git add .
git commit -m "何をしたか日本語でOK"
git push

本番に反映したいとき

.\deploy.ps1

セキュリティチェックリスト

  • ✅ GitHubリポジトリは Private になっているか
  • ✅ app/config.php はGit追跡対象外か（git statusに出ないこと）
  • ✅ deploy.ps1 はGit追跡対象外か
  • ✅ パスワードはパスワードマネージャに保管されているか
  • ✅ コミットする前に git diff --cached でパスワードらしき文字列が混ざっていないか確認
万が一パスワードをコミット/push してしまったら:
即座に該当パスワードを変更（DB / FTP / GitHub PAT 等）してください。
GitHub履歴からの完全削除は git filter-repo や BFG Repo-Cleaner が必要ですが、「漏洩したパスワードはもう使わない」のが一番確実です。
